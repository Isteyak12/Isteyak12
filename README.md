## 👋 About me

I'm **Isteyak**, currently working on **machine vision system inspections**, building on earlier research at the **GeoVision Lab**, where I trained **Siamese Attention U-Net** models for satellite change detection. I love computer vision, deep learning and creative problem-solving, and lately I've been pointing that toolkit at **robotics**.

```yaml
currently:   industrial computer vision inspection systems
learning:    geospatial deep learning · TensorRT-optimized inference · ROS 2
open_to:     computer vision / AI collaborations
ask_me:      Python · computer vision · full-stack web development
fun_fact:    trained models on everything from satellite imagery to posture-tracking webcams
```
